# Privacy model

Wireless Watch is designed to minimize data movement.

- No account is required.
- No NEXVARY cloud endpoint is used by the scanner.
- Observations and saved sessions stay on the device unless the user explicitly shares a CSV report.
- The current scanner does not connect to discovered Wi-Fi/BLE devices.
- Android permission requirements still apply; some Android versions tie Wi-Fi/BLE discovery to location permission.
- Device addresses may rotate and names may be absent or misleading.
- DULT, Find Hub and Remote ID decoding is based on broadcast protocol fields available to the phone.
- Heuristic signatures based on a name or SSID must not be treated as forensic proof.
